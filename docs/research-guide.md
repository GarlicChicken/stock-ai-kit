# 연구 방법 (`kit.lab`)

신호를 찾고, 그것이 우연이 아닌지 확인하고, 비용을 넣어 백테스트로 다시 보는 순서입니다.

## 도구

| 모듈 · 명령 | 하는 일 |
|---|---|
| `kit.lab.signals` · `uv run kit factor list` | 기본 신호 12종: 모멘텀(20 · 60일 · 12-1개월), 되돌림(1 · 5일), 저변동성, 거래대금 급증, 시가 갭, 52주 고가 근접, 시가총액(대 · 소), 회전율 |
| `kit.lab.factor_test` · `uv run kit factor <신호>` | IC(신호 순위와 앞으로 수익률 순위의 상관), 5분위 평균 수익률, 맨 위 - 맨 아래 차이, 해마다 결과 |
| `kit.lab.robustness` | 플라시보(종목끼리 섞기), 앞 · 뒤 절반, 묶음 부트스트랩 신뢰구간, 다중 검정 보정(Benjamini-Hochberg) |
| `kit.lab.event_study` · `uv run kit event <CSV>` | 공시 · 뉴스 같은 사건 뒤 1~N거래일 누적 초과수익 |
| `kit.lab.calendar` | 거래일 이동, 정보가 나온 시각 → 처음 결정할 수 있는 거래일 |
| `uv run kit backtest --cost-x 1.5` | 비용(수수료 · 세금)을 1.5배로 다시 계산 |

```bash
uv run kit factor reversal_5 --start 2016-01-01 --end 2024-12-31 --horizon 5
uv run python research/examples/factor_lab.py        # 12종 한꺼번에 + p값 보정
```

## 기본 원칙

### 1. 미래 데이터를 쓰지 않는다
- 백테스트 엔진은 오늘까지의 데이터만 전략에 넘기고, 결정은 다음 거래일 시가에 체결합니다.
- 외부 자료는 **기준일이 아니라 알 수 있게 된 시각**으로 붙입니다.

| 자료 | 처음 쓸 수 있는 때 |
|---|---|
| 공시 (DART) | 접수일 장 마감 뒤 → 다음 거래일 시가 |
| 재무제표 숫자 | 그 보고서 공시일 이후 (사업연도 끝이 아님) |
| 뉴스 | 15:30 전 기사는 그날 장 마감 뒤, 이후 기사는 다음 거래일 |
| 투자자별 매매동향 | 장 마감 뒤 공표 → 다음 거래일 |
| 월간 거시 지표 | 다음 달 발표 → 최소 한 달 늦춤 |
| 미국 지수 | 한국 t일 결정에는 미국 t-1일 종가까지 |
| 환율 · 원자재 일봉 | 한국 t일 결정에는 t-2일까지 |
| 분봉 | 봉 시작 시각이 아니라 봉이 끝난 뒤 |

### 2. 생존 편향을 피한다
지금 살아남은 종목만으로 과거를 돌리면 결과가 좋게 나옵니다. 표준 데이터는 그때그때의 시가총액 상위 200개와 상장폐지 종목을 담고 있어 이 편향이 없습니다. 외부에서 종목 목록을 가져올 때도 '그 시점의 목록'인지 확인합니다.

### 3. 비용을 넣는다
- 팔 때 증권거래세(연도별 0.15~0.30%)와 수수료가 단기 전략의 수익을 크게 깎습니다. 자주 사고파는 신호일수록 먼저 비용을 넣어 봅니다.
- `--cost-x 1.5`처럼 비용을 늘려도 결과가 버티는지 봅니다.
- 신호 검증(IC · 5분위)은 비용을 빼기 전 값입니다. 쓸 만해 보이면 전략 파일로 만들어 백테스트합니다.

### 4. 우연이 아닌지 확인한다
- **기간 나누기**: 앞 · 뒤 절반, 해마다 같은 방향인지. 한 해에 몰린 결과는 믿기 어렵습니다.
- **플라시보**: 신호를 종목끼리 무작위로 섞어도 비슷하게 나오면 진짜가 아닙니다.
- **여러 번 시험했으면 보정**: 신호 20개를 시험하면 1개쯤은 우연히 좋아 보입니다. p값을 보정해서 봅니다.
- **미리 정하고 한 번만 판정**: 규칙과 판정 날짜를 먼저 적어 두고, 그 날 한 번만 봅니다. 결과를 매일 들여다보다 좋아 보이는 날 판정하면 아무 효과 없는 규칙도 절반 가까이 통과합니다.
- **같은 조건끼리 비교**: 규칙을 조금씩 바꾼 변형은 같은 기간 · 같은 비용에서 짝지어 비교합니다. 난수 시드만 바꿔도 순위가 바뀌는 차이는 차이가 아닙니다.
- **이벤트 수가 적으면 조심**: 수십 건짜리 결과는 몇 건만 빠져도 뒤집힙니다.

### 5. 단위와 결측을 조심한다
- 금액 단위가 출처마다 다릅니다(원 · 천원 · 백만원). 연동 모듈은 원으로 맞춰 돌려줍니다.
- 값이 없는 날은 0이 아니라 '값 없음'입니다. 거래정지일은 시가 0 · 거래량 0으로 오고, 키트는 거래 불가로 처리합니다.
- 원 단위 금액 그대로 비교하면 큰 회사가 늘 커 보입니다. 비율(수익률 · 평소 대비)로 봅니다.
- 수집이 조용히 멈춰 값이 비는 일이 흔합니다. 받은 건수가 0이면 오류로 다룹니다.

## 자주 보고되는 경향 (직접 확인해 보기)
국내 일봉 연구에서 흔히 보고되는 것들입니다. 기간 · 종목 · 비용에 따라 달라지니 키트로 직접 검증합니다.
- 짧은 기간(하루~일주일) 많이 떨어진 종목이 되돌아오는 경향, 시가 갭이 장중에 되돌려지는 경향. 다만 회전이 커서 비용을 넣으면 크게 줄어듭니다.
- 변동성이 낮은 종목이 위험 대비 성과가 나은 경향.
- 자기주식 취득 같은 일부 공시 뒤의 단기 초과수익. 이벤트 수와 정정 공시 처리에 따라 달라집니다.
- 뉴스 · 감성 신호는 기사가 많은 대형주 효과와 섞이기 쉬워, 종목 · 날짜 효과를 빼면 사라지는 경우가 많습니다.
- 거시 지표로 지수 방향을 맞히는 규칙은 기간을 나눠 보면 버티지 못하는 경우가 많습니다.
