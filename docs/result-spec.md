# 결과 CSV 양식

모든 결과는 같은 양식의 CSV 하나로 나옵니다. 각자 따로 연구하고 시험해도, 진행자가 모아서 한 화면에 재생할 수 있게 하기 위해서입니다.

- 멤버: `uv run kit submit <전략 파일> --name <이름> --team <팀 이름>`을 실행하면 모의투자 기간(설정값)의 CSV가 만들어집니다. 그 파일 하나를 보냅니다.
- 진행자: 받은 CSV들을 키트 폴더의 `race.html`에 끌어다 놓으면 바로 재생됩니다.
- 키트로 백테스트할 때도 `outputs/<전략 파일 이름>/result.csv`가 같은 양식으로 저장됩니다.
- 키트 밖(엑셀 · 다른 프로그램)에서 계산했어도 이 양식만 맞추면 레이스에 참가할 수 있습니다.
- 양식에 맞는지는 `uv run kit validate <파일>`로 확인합니다.

## 열

| 열 | 뜻 | 형식 · 규칙 |
|---|---|---|
| `date` | 거래일 | `YYYY-MM-DD`. 오름차순, 겹치지 않게, 기간 안의 거래일을 빠짐없이 |
| `name` | 이름 · 닉네임 | 모든 줄이 같은 값 |
| `strategy` | 전략 이름 | 모든 줄이 같은 값 |
| `equity` | 평가금액 (원) | 정수. `cash + stock_value` |
| `cash` | 현금 (원) | 정수, 0 이상 |
| `stock_value` | 주식 평가액 (원) | 정수, 0 이상. 그날 종가 기준 |
| `return` | 누적 수익률 | 소수 6자리. `equity ÷ 시작 금액 - 1` (0.123456 = +12.3456%) |
| `drawdown` | 고점 대비 하락률 | 소수 6자리, 0 이하. `equity ÷ 그때까지 최고 equity - 1` |
| `positions` | 보유 종목 수 | 정수, 0 이상 |
| `team` (선택) | 팀 이름 | 있으면 모든 줄이 같은 값. 레이스의 [팀] 보기에서 팀원 평균을 낼 때 씀 |

- 파일: UTF-8(BOM 있음, 엑셀에서 한글이 깨지지 않게), 쉼표 구분, 첫 줄은 열 이름, 열 순서는 위 표 그대로 (`team`은 맨 뒤, 없어도 됨)
- 기간: 모의투자 기간(설정 `compare_start` ~ `compare_end`, 지금 2023-01-02 ~ 2025-12-30). 첫 줄이 시작일(또는 그 뒤 첫 거래일), 마지막 줄이 끝 날짜(또는 그 전 마지막 거래일)
- 시작 금액 1억 원(설정 `initial_cash`). 첫날은 아직 사기 전이라 `equity = 100000000`, `return = 0`
- 파일 이름: `<팀>_<이름>_<전략>.csv` (이름 · 팀은 파일 안의 칸으로 정해지므로 파일 이름은 바뀌어도 됨)

## 예시

```csv
date,name,strategy,equity,cash,stock_value,return,drawdown,positions,team
2023-01-02,지민,모멘텀 상위 10,100000000,100000000,0,0.000000,0.000000,0,1팀
2023-01-03,지민,모멘텀 상위 10,99210450,205300,99005150,-0.007896,-0.007896,10,1팀
2023-01-04,지민,모멘텀 상위 10,101336820,205300,101131520,0.013368,0.000000,10,1팀
```

## 키트 밖에서 만들 때

- 거래일 목록: `uv run kit data calendar --start <시작일> --end <끝 날짜>` (outputs 폴더에 CSV로 저장)
- 현금 · 주식 평가액 · 보유 종목 수를 모르면 `cash = equity`, `stock_value = 0`, `positions = 0`으로 둡니다.
- 재생에 꼭 필요한 열은 `date, name, strategy, equity`이지만, 점검(`kit validate`)을 통과하려면 모든 열이 있어야 합니다.

## 백테스트 폴더에 함께 저장되는 파일 (참고용)

키트로 백테스트하면 `result.csv` 옆에 아래 파일도 저장됩니다. 진행자에게 보낼 필요는 없습니다.

| 파일 | 내용 |
|---|---|
| `weights.csv` | 리밸런싱한 날의 목표 비중 (`date, code, name, weight`) |
| `trades.csv` | 거래 내역 (`date, code, name, side, qty, price, amount, fee, tax`) |
| `meta.json` | 전략 설명 · 기간 · 데이터 지문 · 요약 지표 |
| `report.html` | 브라우저로 보는 리포트 |
