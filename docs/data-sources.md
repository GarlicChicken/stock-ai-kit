### 투자 대상에서 빼는 종목

| 빼는 것 | 거르는 방법 |

| 우선주 | 종목코드 끝자리가 0이 아님 (예: 005935, 00680K) |
| 스팩 | 이름에 '스팩'. 합병해서 일반 회사가 된 뒤에는 포함 |
| 뮤추얼펀드 · 선박투자회사 | 이름이 '숫자+호' 또는 'MF'로 끝남, 그리고 이름이 바뀐 펀드는 종목코드 목록으로 |
| 리츠 · 인프라펀드 | 이름이 '리츠'로 끝남(인터리츠 제외), 맥쿼리인프라 등 |

2025년부터 새로 상장하는 종목은 영문이 섞인 코드(예: 삼성에피스홀딩스 0126Z0)를 받습니다. 끝자리가 0이면 보통주로 보고 포함합니다.

### 수정주가

- 원천 파일에는 그날 실제 가격만 저장하고, 수정주가는 불러올 때 계산합니다.
- 거래소가 매일 정하는 **기준가**(종가 - 전일 대비)로 하루 수익률을 이어 붙입니다. 그래서 액면분할 · 병합 · 무상증자 · 감자 · 인적분할이 모두 거래소 기준대로 반영됩니다.
- 2024-12-30 종가를 실제 가격과 같게 맞춥니다(`config/kit.toml`의 `adjust_anchor`). 이 기준일이 같으면 데이터의 끝 날짜가 달라도 같은 수정주가가 나옵니다.
- 대조 결과 (2026-11 확인)
  - FinanceDataReader 수정주가와 2016~2024년 누적 수익률 차이: 삼성전자 · SK하이닉스 · 현대차 0.00%, 에코프로비엠 0.01%, 카카오 0.39%(시장 이전 상장일 처리 차이)
  - yfinance와 2000~2014년 누적 수익률 차이: 삼성전자 · POSCO · 현대차 0.00%. SK하이닉스 · NAVER는 yfinance 쪽에 날짜 누락 · 분할 처리 오류가 있음

### 원천 데이터에서 바로잡은 것

- 2000-05-26 이전 기록은 종목코드 앞의 0이 빠져 있어(5930) 6자리로 맞춥니다.
- 거래정지일은 시가 · 고가 · 저가가 0, 거래량 0으로 옵니다. 키트는 이날을 '거래 불가'로 처리합니다.

### 주의할 점

1. 상장폐지 직전 정리매매 기간은 가격제한폭이 없어 하루에 -70% 같은 움직임이 나옵니다. 실제 기록입니다.
2. 거래정지가 풀린 날도 가격제한폭을 넘는 움직임이 나올 수 있습니다.
3. 배당은 반영하지 않습니다.
4. 원천 데이터는 한 사람이 매일 자동으로 올리는 공개 저장소입니다. 하루 이틀 늦게 갱신될 수 있습니다(2026-11-18 기준 11-16까지).

## 다른 출처 (키트에 함께 설치, 연구용)

`kit.sources`의 함수가 출처와 관계없이 같은 모양으로 돌려줍니다. 연결 상태는 `uv run kit sources`로 한 번에 확인합니다.

| 출처 | 주는 것 | 로그인 · 키 | 분봉 |
|---|---|---|---|
| marcap (`get_marcap`) | 한 해의 전 종목 일별 데이터 (상장폐지 포함, 수정 전 가격) | 필요 없음 | 없음 |
| FinanceDataReader | 일봉(국내 · 미국), 지금 상장된 종목 목록, 지수 | 필요 없음 | 안 됨 (네이버 분봉 페이지가 닫힘) |
| yfinance | 일봉, 분봉 | 필요 없음 | 됨 |
| pykrx | 일봉(수정주가) | 일봉은 필요 없음 | 없음 |

```python
from kit.sources import get_daily, get_minute, get_listing, get_index, get_marcap

get_daily("005930", "2024-01-01", "2024-12-31")                    # FinanceDataReader
get_daily("005930", "2024-01-01", source="yahoo", market="KOSPI")  # yfinance
get_minute("005930", interval="1m", days=5)                        # 분봉 (yfinance)
get_listing("KRX")                                                 # 지금 상장된 종목 목록
get_index("KOSPI", "2000-01-01")                                   # 지수 종가 (1995년부터)
get_marcap(2024)                                                   # 2024년 전 종목 일별 데이터
```

- 일봉: `date, code, open, high, low, close, volume` · 분봉: `datetime, code, ...` (한국 시각)
- **2026-09-14부터 네이버 일봉(FinanceDataReader · pykrx)의 종가는 공식 종가와 다릅니다.** 거래소 애프터마켓(16:00~20:00)이 생긴 뒤로 네이버는 애프터마켓이 끝날 때 가격을 종가로 줍니다. 표준 데이터(marcap)와 yfinance는 공식 종가(15:30)입니다.
- 네이버 일봉은 최근 3,000거래일(2014-08 이후)까지만 받아집니다.
- 무료 분봉은 오래 보관되지 않습니다: 1분봉 최근 8일, 2~30분봉 60일, 60분봉 730일. 계속 모으려면 `uv run kit data minute <코드>`를 매일 실행합니다.
- pykrx의 시가총액 · 투자자별 매매 · 공매도 같은 기능은 한국거래소(KRX) 회원 로그인이 필요합니다.
- 출처는 예고 없이 바뀌거나 막힐 수 있습니다. 이상하면 `uv run kit sources`로 먼저 확인합니다.

## 키가 필요한 출처 (키트에 없음, 참고)

| 출처 | 쓰임 | 비고 |
|---|---|---|
| 증권사 API (한국투자증권 · 키움 등) | 실시간 시세 · 분봉 · 모의투자 | 계좌 · 앱키 필요 |
| DART OpenAPI | 공시 · 재무제표 | 무료 키, 키당 2만 건 한도 |
| 한국은행 ECOS | 금리 · 환율 등 거시 지표 | 무료 키 |
| KRX Open API · 공공데이터포털 | 거래소 공식 시세 | 키 필요, 받은 데이터 재배포 금지 |

키는 사람마다 따로 발급받고 다른 사람과 나눠 쓰지 않습니다(한도가 합쳐짐). 키는 `.env` 파일에 두고 저장소에 올리지 않습니다.
